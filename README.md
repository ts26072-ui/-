# 익명방

닉네임 없이 쓰는 익명 커뮤니티 앱이에요. 방은 하나로 고정돼 있고, 게시판·사진/영상·익명 1:1 대화가 있어요.

## 기능
- **고정 방 1개**: 코드 없이 모두 같은 방에 들어와요. 관리자가 "방 삭제"를 누르면 새 방이 열려요.
- **게시판(디시 스타일)**: 번호, 조회수, 추천, 댓글, 개념글(추천 3개 이상). 글쓴이는 모두 "ㅇㅇ"로 표시돼요.
- **사진·영상 첨부**: 채팅, 게시글(최대 4개), 1:1에서 사용. 사진 10MB, 영상 40MB까지.
- **익명 1:1**: 채팅·게시글·댓글의 "1:1"을 누르면 그 글쓴이에게 요청이 가요.
  상대는 누구인지 모른 채 수락하면 대화가 시작돼요. 거절은 요청한 쪽에 알려지지 않아요.
- **안전장치**: 신고(서로 다른 3명이면 자동으로 가려짐), 1:1 차단·신고(관리자에게 최근 대화 전달),
  관리자 삭제·작성자 차단, 도배 제한, 미응답 1:1 요청은 최대 5개까지.
- 작성자 정보는 서버 안에서만 쓰이고 다른 사람에게는 전달되지 않아요.

## 1. 서버 실행
```
node server.js   # http://localhost:3000  (외부 패키지 설치 불필요)
node test.js     # 동작 테스트
```

## 2. Railway 설정 (중요)
**환경변수** (서비스 → Variables)
| 이름 | 값 | 설명 |
|---|---|---|
| `ADMIN_KEY` | 직접 정한 긴 비밀번호 | 설정 탭에서 관리자 로그인할 때 써요. 없으면 관리자 기능이 꺼져요 |
| `DATA_DIR` | `/data` | 글·사진·영상이 저장될 위치 |

**Volume** (서비스 → 우클릭/`+ Create` → Volume, Mount path를 `/data` 로)
Volume이 없으면 서버가 다시 배포되거나 재시작될 때마다 글과 사진이 모두 사라져요.
플랜에 따라 Volume 사용 조건이 다를 수 있으니 Railway에서 확인하세요.

## 3. 화면 파일 위치
서버는 `public/index.html` 을 먼저 찾고, 없으면 저장소 맨 위의 `index.html` 을 써요.

## 4. APK
`capacitor.config.json` 의 `server.url` 에 Railway 주소를 넣고 Actions의 "Build APK"를 실행하세요.
앱이 서버 화면을 불러오는 방식이라 **기능을 고쳐도 APK를 다시 만들 필요가 없어요.**

## 알아둘 점
- 같은 방 사람들에게는 익명이지만, 서버 운영자는 접속 기록(IP 등)을 볼 수 있어요. 완전한 익명이라고 약속하지 마세요.
- 익명 ID는 기기(앱)마다 따로 생겨요. iPhone에서 Safari와 홈 화면 앱은 서로 다른 ID라 1:1 대화가 이어지지 않아요.
- 신고된 1:1 대화는 관리자가 볼 수 있어요. 그 외의 1:1 내용은 관리자도 볼 수 없어요.
