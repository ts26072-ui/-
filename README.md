# 익명방 — 닉네임 없는 익명 채팅방

닉네임·계정 없이 방 코드만으로 들어와 대화하는 앱이에요. 메시지에는 작성자 정보가 붙지 않아요.

## 기능
- 방 만들기 / 5자리 코드로 입장
- 닉네임 없음, 작성자 표시 없음
- **신고**: 서로 다른 3명이 신고하면 메시지가 모두에게 자동으로 가려져요
- **방장 관리**: 방을 만든 사람은 메시지를 삭제할 수 있어요
- 도배 방지(1.2초 간격), 최근 100개 메시지만 메모리에 보관(서버 재시작 시 삭제)
- 화면에 "특정인 저격 금지" 약속을 항상 안내

## 1. 서버 실행
```
node server.js   # http://localhost:3000  (외부 패키지 설치 불필요)
node test.js     # 동작 테스트
```
친구들이 쓰려면 서버가 인터넷에 올라가 있어야 해요. Render, Railway, Fly.io 같은 곳에
이 폴더를 올리면 `https://내서버주소` 가 생겨요. 시작 명령은 `node server.js` 예요.

## 2. APK 만들기 (GitHub Actions 사용)
1. `capacitor.config.json` 의 `server.url` 을 위에서 만든 서버 주소로 바꿔요.
2. 이 폴더를 GitHub 저장소에 올려요.
3. 저장소의 **Actions → Build APK → Run workflow** 를 실행해요.
4. 끝나면 **Artifacts → anon-chat-apk** 에서 `app-debug.apk` 를 받아요.
5. 폰에서 설치할 때 "출처를 알 수 없는 앱 허용"을 켜야 해요.

PC에 Android Studio가 있다면 `npm install && npx cap add android && npx cap open android` 로도 만들 수 있어요.

## 알아둘 점
- 같은 방 사람들에게는 익명이지만, 서버를 운영하는 사람은 접속 기록(IP 등)을 볼 수 있어요. 완전한 익명이라고 약속하지는 마세요.
- 이 앱은 친구끼리 쓰는 소규모용이에요. 괴롭힘 신고가 들어오면 방장이 방을 닫거나 삭제해 주세요.
