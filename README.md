# 금베 — 닉네임 없는 익명 커뮤니티

채팅 · 게시판 · 쇼츠 · 1:1 · 영어사전 · 내 필기 노트(손글씨) · 대한민국 지도 · 대구과학고 1학년 시간표/급식 · 신청 현황 · 오픈소스 라이선스. 닉네임과 계정 없이 쓰고, 다른 사람에게는 작성자 정보가 보이지 않아요.

## 폴더 구조
```
server.js              서버 (외부 패키지 불필요, Node.js 18 이상)
public/index.html      앱 화면 (웹·APK 공용)
public/manifest.json
capacitor.config.json  APK 설정 (앱 이름: 금베)
test.js                동작 테스트
```

## 서버 실행
```
node server.js     # http://localhost:3000
node test.js       # 동작 테스트
```
환경변수: `PORT`, `ADMIN_KEY`(설정하면 관리자 기능이 켜져요), `DATA_DIR`(글·업로드 저장 위치, 기본 `./data`)

- `NEIS_KEY`: 시간표·급식에 필요해요. [open.neis.go.kr](https://open.neis.go.kr) 에서 무료로 인증키를 받아 서버 환경변수로 넣으세요. 학교 코드는 서버가 "대구과학고등학교"를 NEIS에서 직접 찾아 쓰고(`SCHOOL_CODE`로 직접 지정도 가능), 시간표는 1학년 반 목록을 NEIS에서 받아 보여줘요.
- **Railway에서 NEIS_KEY 넣는 법**: 프로젝트 → 서비스 → **Variables** → `NEIS_KEY` = 발급받은 키 → 저장하면 자동 재배포돼요. 키는 코드·GitHub에 직접 적지 마세요(공개 저장소면 누구나 쓸 수 있어요).
- **내 필기 노트**: 더보기 → 내 필기 노트. 펜·형광펜·지우개, 두께 조절, 16색+직접 고르기, 사진 넣기(이동·크기 조절·삭제), PDF·사진 파일 위에 필기, 이미지로 저장, 두 손가락 확대/축소, 되돌리기, 줄/모눈 배경, 페이지 늘리기. 노트는 **서버가 아니라 이 기기(브라우저/앱)** 에 저장돼서 다른 사람에게 보이지 않아요. 앱 데이터를 지우면 노트도 사라져요.
- **수행평가 일정 · 과목별 평가기준**: 더보기 → 평가기준 · 수행평가 일정. 이 기기에만 저장돼요(서버 없음). 3일 안에 있는 수행평가는 앱을 열 때 알려줘요.
- 신청 현황(분임토의실·LOD·수강신청)은 관리자가 항목(제목·정원)을 만들면 학생이 신청/취소해요. 신청자는 익명이고 인원수만 보여요.
- 글·쇼츠·업로드 파일은 `DATA_DIR`에 저장돼요. Render·Railway 무료 플랜은 재배포 때 디스크가 지워지니, 남기고 싶으면 영구 디스크(Volume)를 붙이고 `DATA_DIR`을 그 경로로 지정하세요.
- 영어사전은 서버가 외부 사전 서비스(dictionaryapi.dev, MyMemory)에 접속해서 가져와요. 서버가 인터넷에 연결돼 있어야 해요.
- 업로드 한도: 사진 10MB, 영상 40MB(쇼츠는 60초). 아이폰 영상(mov)은 일부 안드로이드에서 재생이 안 될 수 있어서 mp4 권장.

## 구글 클래스룸 연결 (선택)
학생이 구글 계정을 연결하면 클래스룸 학습지(PDF·사진·구글 문서)를 앱으로 가져와 **내 필기 노트**에서 바로 필기해요. 더보기 → 평가기준 · 수행평가 일정 → **클래스룸 학습지**. 앱을 열 때 새 학습지가 있으면 알려줘요. (백그라운드 자동 저장은 아니고, 앱을 열었을 때 확인 → "모두 노트로 가져오기" 방식이에요.)

서버 환경변수 3개가 필요해요. 없으면 화면에 "설정이 아직 없어요"라고만 나오고 다른 기능은 그대로예요.
- `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`, `PUBLIC_URL`(예: `https://내서버.up.railway.app`, 끝에 `/` 없이)

설정 순서
1. [Google Cloud Console](https://console.cloud.google.com) 에서 프로젝트를 만들고 **Google Classroom API**, **Google Drive API** 를 사용 설정해요.
2. **OAuth 동의 화면**을 만들고(범위: classroom.courses / coursework.me / courseworkmaterials / announcements 읽기 전용, drive.readonly), 쓸 학생 계정을 **테스트 사용자**로 추가해요.
3. **사용자 인증 정보 → OAuth 클라이언트 ID → 웹 애플리케이션** 을 만들고, 승인된 리디렉션 URI에 `PUBLIC_URL/api/gc/callback` 을 넣어요.
4. Railway **Variables** 에 위 3개를 넣으면 재배포돼요.

알아둘 점
- 학교(Workspace) 관리자가 외부 앱 연결을 막아 두었으면 학교 계정으로는 연결되지 않아요. 이 경우 학교 계정이 아닌 방법은 없어요.
- 동의 화면이 "테스트" 상태이면 구글 정책상 연결이 7일마다 풀려서 다시 연결해야 해요. 공개로 바꾸려면 구글 검증이 필요해요(drive.readonly 는 제한 범위).
- 연결 정보(refresh token)는 `DATA_DIR/db.json` 에 저장돼요. 서버 운영자가 볼 수 있으니 믿을 수 있는 사람만 운영하고, 파일을 공개하지 마세요. 앱에서 "연결 끊기"를 누르면 서버에서 지우고 구글에도 폐기 요청을 보내요.
- 클래스룸 첨부 중 PDF·사진·구글 문서(PDF로 변환)만 노트로 열 수 있어요. Word·PPT·한글 파일은 목록에 보이지만 열 수 없다고 표시돼요.

## APK 만들기 (GitHub Actions)
1. `capacitor.config.json` 의 `server.url` 을 서버 주소로 바꿔요.
2. 저장소에 올리고 **Actions → Build APK → Run workflow** 실행.
3. **Artifacts → anon-chat-apk** 에서 `app-debug.apk` 를 받아요.

## 알아둘 점
- 같은 방 사람들에게는 익명이지만, 서버 운영자는 접속 기록(IP 등)을 볼 수 있어요. 완전한 익명이라고 약속하지는 마세요.
- 신고 3명이면 자동으로 가려지고, 관리자는 삭제·차단·방 초기화를 할 수 있어요.
